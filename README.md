# 오늘의 지면

실시간 인터넷 뉴스 피드 대신 **종이신문 지면에 실린 기사 순서**로 읽기 위한 개인용 웹 MVP입니다.

## 화면
- 날짜 선택
- 신문사 선택
- `1면 / 2면 / 3면 ...` 선택
- 지면 기사 제목 + 짧은 설명 + 신문사 원문 링크
- 모바일 대응

## 현재 샘플
- 매일경제: 공개된 `오늘의 매경` 지면 목차 형태에 맞춰 1면/2면 샘플 포함
- 동아일보: 공개 `지면보기` 목차 형태의 샘플 포함
- 한겨레/경향신문: 로그인·유료 지면보기이므로 원문 복제 없이 공식 지면 링크만 연결
- 조선/중앙/한국경제/서울신문: 각 사이트 구조에 맞는 adapter 추가 필요

## 로컬 실행
브라우저의 `fetch()` 때문에 파일을 직접 더블클릭하지 말고 간단한 로컬 서버를 실행하세요.

```bash
python -m http.server 8000
```

그 뒤 `http://localhost:8000` 접속.

## 매일 자동화
`.github/workflows/daily.yml`은 매일 오전 7:30(KST)에 `scraper.py`를 실행하고
`data/latest.json`을 갱신하도록 구성했습니다.

GitHub Pages를 켜면 데이터 업데이트 후 정적 웹도 자동으로 최신 데이터로 표시됩니다.

## 중요한 운영 원칙
1. 로그인/구독/유료벽을 우회하지 않습니다.
2. 기사 전문을 저장하거나 재배포하지 않습니다.
3. 제목, 면수, 섹션, 짧은 메타데이터, 원문 링크만 다룹니다.
4. 실제 배포 전 각 신문사의 robots.txt 및 이용약관을 확인하세요.
5. 사이트 HTML 구조가 바뀌면 해당 신문사 adapter를 수정해야 합니다.

## 다음 구현 우선순위
`collect_mk()`와 같은 방식으로 publisher adapter를 신문사별 파일로 분리하고,
`data/YYYY-MM-DD.json` 형태로 날짜별 저장을 추가하면 과거 신문까지 탐색할 수 있습니다.
